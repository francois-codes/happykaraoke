# Claude Code Configuration

This directory contains configuration and context files for working with Claude Code on this repository.

## 📁 Files

### `context.md`
Quick context summary for starting new Claude Code sessions.

**Purpose:** Rapid orientation - read this first in any new session to understand the project.

**Contains:**
- High-level overview
- Essential file locations
- Critical gotchas
- Quick reference for common tasks
- Mental models

### `rules.md`
Comprehensive rules and best practices for working with this codebase.

**Purpose:** How to work effectively - guidelines for making changes.

**Contains:**
- Core principles (plan first, check git, keep it simple)
- Architecture patterns to follow
- Common pitfalls to avoid
- Pre-change checklist
- Code style conventions
- Investigation strategies
- Debugging context
- Communication preferences

## 🚀 Usage

### For Claude Code Assistant

**At the start of each session:**
1. Read `context.md` for quick orientation
2. Read `rules.md` for work guidelines
3. Consult project documentation as needed:
   - `QUICK_REFERENCE.md` - Fast lookups
   - `ARCHITECTURE.md` - Deep dive
   - `DEVELOPER_GUIDE.md` - Workflows
   - `SONG_FORMAT.md` - Song files

**During work:**
- Reference `rules.md` for patterns
- Check `context.md` for quick lookups
- Follow the workflow: plan → approve → implement

### For Developers

These files document:
- How Claude Code should work with this repo
- Common patterns and conventions
- Critical considerations (scroll complexity, multi-device, etc.)
- Architecture constraints

**You can:**
- Update these files as the project evolves
- Add new patterns or gotchas as discovered
- Refine rules based on experience
- Use them as onboarding docs for new contributors
